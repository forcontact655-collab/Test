# Echo — мессенджер

Статический веб-клиент мессенджера: личные чаты с E2E-шифрованием, группы, каналы,
стикеры, реакции, профили с фоном и музыкой. Работает поверх Supabase (Auth, Postgres,
Realtime, Storage). Без сборки — открывается как обычный сайт.

```
messenger/
├─ index.html          разметка-каркас (экраны, панели, шторки)
├─ style.css           дизайн-система: токены, компоненты, адаптив
├─ app.js              вся логика клиента
├─ e2e.js              ECDH + AES-GCM для личных чатов
├─ store.js            IndexedDB: кэш, черновики, очередь отправки
├─ media.js            сжатие фото и видео перед загрузкой
├─ demo.js             демо-режим на локальных данных (?demo=1)
├─ vendor/supabase.js  supabase-js (собран в один файл)
├─ sw.js               офлайн-кэш оболочки
└─ manifest.webmanifest
```

## Дизайн

Тёмно-фиолетовая тема, переработанная под привычки современных мессенджеров
(Telegram, Discord, Signal): меньше «коробок», больше воздуха, спокойные поверхности,
один акцентный градиент и мягкие тени вместо жёстких рамок.

**Токены** — начало `style.css`, блок `:root`. Всё остальное использует только их:

| Группа | Переменные |
| --- | --- |
| Поверхности | `--bg`, `--bg-2`, `--surface` … `--surface-5` |
| Линии | `--line`, `--line-2`, `--line-3` |
| Текст | `--text`, `--text-2`, `--muted`, `--dim` |
| Акценты | `--acc`, `--acc-2`, `--acc-3`, `--grad`, `--me` |
| Радиусы | `--r-xs` … `--r-2xl`, `--r-full` |
| Тени | `--shadow-1` … `--shadow-3`, `--glow` |
| Движение | `--ease`, `--ease-out`, `--t-fast`, `--t`, `--t-slow` |

Поменяв `--acc*`, `--grad` и `--me`, тему можно перекрасить целиком.

**Что изменилось в интерфейсе**

- **Каркас.** Боковая панель 348 px со стеклянной подложкой, лента сообщений с
  ограничением по ширине (`--content-w`), фон приложения — мягкие фиолетовые пятна
  света. Никаких двойных градиентов и «стеклянных коробок» внутри коробок.
- **Список чатов.** Единая строка 50 px: аватар, имя, превью, время и бейдж.
  Активный чат помечен градиентной подложкой и световой полоской слева,
  закреплённый — точкой. Папки («Все», «Личные», «Группы», «Каналы», …) —
  компактные чипы в две строки, больше не уезжают за край на телефоне.
- **Шапка чата.** Полупрозрачная, с размытием и тонкой световой линией снизу.
  Статус «печатает…» получил анимированные точки.
- **Лента.** Сообщения одного автора подряд (до 5 минут) склеиваются в цепочку:
  общий аватар, срезанные внутренние углы, время только у последнего.
  В группах и каналах слева появился рельс с аватарами, как в Discord.
  Хвостик пузыря смотрит в сторону автора, свои сообщения — акцентный градиент.
- **Реакции.** Компактные пилюли с подсветкой «моих», аккуратный ховер.
- **Композер.** Одна капсула с фокус-свечением, круглая кнопка отправки с градиентом,
  панель стикеров и смайлов в той же стилистике.
- **Профиль.** Баннер с мягким светом и затемнением, «сворачивающийся» аватар,
  стеклянные карточки информации, карточка музыки с виниловым диском.
- **Настройки.** Группы строк внутри одной карточки, цветные плитки-иконки,
  отдельные подстраницы вместо нагромождения шторок.
- **Мелочи.** Единая типографика (Inter/SF Pro, табличные цифры для времени),
  одинаковые радиусы и тени, аккуратный `focus-visible`, поддержка
  `prefers-reduced-motion`, фолбэк без `backdrop-filter`, адаптив с 900 px.

**Горячие клавиши.** `/` или `Ctrl/⌘ + K` — фокус на поиске, `Esc` — закрыть меню/шторку,
`Enter` — отправить, `Shift + Enter` — перенос строки.

## Демо-режим

```
index.html?demo=1         открыть интерфейс с локальными тестовыми данными
index.html?demo=1&auth=1   показать экран входа
```

`demo.js` подменяет `createClient` на мини-эмулятор Supabase (select/insert/update/
upsert/delete, вложенные выборки, realtime-заглушка, нужные RPC). Ни один запрос
не уходит в сеть, реальные данные и аккаунт не затрагиваются — удобно смотреть
и обсуждать дизайн без входа. Без `?demo` файл ничего не делает.

## Запуск

Любой статический сервер из корня репозитория:

```bash
python3 -m http.server 8080
# http://localhost:8080/messenger/index.html
```

Supabase уже настроен в `app.js` (`SUPA_URL`, публичный `anon` ключ).
Схема БД и RLS — в `supabase/schema.sql`.
