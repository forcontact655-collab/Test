Ритм-игра: ноты Tap, Drag, Flick и Hold, линия суждения, три трека и четыре сложности. Игра для Android.

Скачать APK
  • Версия: последняя сборка из ветки arena
  • Android: 7.0 и новее
  • Тип: debug-сборка, не из Google Play
  1. Нажми «Скачать APK» и открой файл из папки «Загрузки».
  2. Если Android попросит, разреши установку из этого источника.
  3. Установи и запусти. Поворот экрана в игре зафиксирован на альбомный.
Все сборки (релиз apk-latest) Играть в браузере

Сборка делается GitHub Actions из репозитория forcontact655-collab/Test. Если установка не получается, напиши, какая у тебя версия Android и модель телефона.
